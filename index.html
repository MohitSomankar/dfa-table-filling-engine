Install this app

Your browser has not offered a one-click install. Use the option for your browser:

  • Chrome or Edge on desktop: click the install icon at the right end of the address bar, or open the browser menu and choose Install.
  • Safari on Mac: File menu, Add to Dock.
  • Safari on iPhone or iPad: Share, then Add to Home Screen.
  • Chrome on Android: menu, Install app.

Installing needs the page to be served over HTTPS (or localhost), not opened as a file.
